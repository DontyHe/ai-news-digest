## New Papers Since Last Check (2026-07-04)

### 1. Patch Policy: Efficient Embodied Control via Dense Visual Representations (NEW)
- **arXiv**: 2607.18236
- **Published**: 2026-07-20
- **Authors**: Gaoyue Zhou, Zichen Jeff Cui, Ada Langford, Bowen Tan, **Yann LeCun**, Lerrel Pinto
- **Categories**: cs.RO, cs.LG
- **Summary**: Leverages pretrained dense ViT features for robot learning instead of compressing observations into single tokens or training visual backbones from scratch. Preserves fine-grained spatial detail from large-scale visual pre-training.

### 2. Separating Representation from Reconstruction Enables Scalable Text Encoders (NEW)
- **arXiv**: 2607.04011
- **Published**: 2026-07-04
- **Authors**: Megi Dervishi, Mathurin Videau, **Yann LeCun**
- **Categories**: cs.CL, cs.AI
- **Summary**: Argues BERT's flat design couples representation learning to reconstruction, making representations increasingly unexploitable by frozen probes despite improved perplexity. Proposes separating representation from reconstruction to enable scalable text encoders.
- **Link**: https://arxiv.org/abs/2607.04011

### 3. AdaJEPA: An Adaptive Latent World Model (MISSED in previous digest)
