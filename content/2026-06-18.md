## 1. WAM-RL: 通过世界-动作模型进行VLA的在线RL微调

- **arXiv ID**: 2606.17906
- **链接**: https://arxiv.org/abs/2606.17906
- **作者**: 来自多个机构的协作团队
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

WAM-RL 提出了一种将世界模型 (World Model) 与动作生成 (Action Model) 联合训练的方法，用于 VLA 模型的在线强化学习微调。与传统的先训练世界模型再训练策略的方式不同，WAM-RL 在 RL 微调过程中联合优化世界预测和动作生成能力，使得模型在学习新任务时能够同时提升对物理世界的理解。

### 方法架构

1. **World-Action Model (WAM)**: 统一的模型架构，同时预测下一帧观测和生成动作。世界预测分支和动作生成分支共享骨干网络的特征表示。
2. **联合训练目标**: 世界预测损失 (next-frame prediction loss) 与 RL 奖励信号协同优化。世界预测提供 dense 的辅助监督信号，缓解 RL 中的 sparse reward 问题。
3. **在线微调流程**: 从预训练 VLA 模型初始化，通过在线交互收集数据，交替更新世界预测头和动作生成头。

### 关键创新点

- **联合世界-动作学习**: 世界模型不再是独立的前置步骤，而是与动作生成协同进化，避免世界模型与策略不匹配的问题
- **Dense 辅助信号**: 世界预测 loss 提供 per-step 的训练信号，有效缓解 VLA 在线 RL 中稀疏奖励的困难
- **高效部署**: 统一模型不需要额外的世界模型推理开销

### 实验结果

在多个机器人操控基准上验证，WAM-RL 相比纯 RL 微调方法在样本效率和最终性能上都有显著提升。世界预测的加入让模型在探索过程中更有效地利用收集到的数据。

### 对具身智能工程师的启示

这种"世界模型即辅助监督"的思路值得关注。VLA 在线 RL 最大的瓶颈是稀疏奖励导致样本效率低下，WAM-RL 通过世界预测提供 dense signal 是一种优雅的解决方案。如果在自己的 VLA 系统中需要做 RL 微调，可以参考这种联合训练范式，而不是单独训练世界模型。

## 2. ThinkingVLA: 具备推理能力的视觉语言动作模型

- **arXiv ID**: 2606.17937
- **链接**: https://arxiv.org/abs/2606.17937
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

ThinkingVLA 将"慢思考"(slow thinking) 能力引入 VLA 模型，使模型在执行动作之前先进行显式的推理规划。类似于 o1/o3 在语言模型中的推理链 (Chain-of-Thought) 机制，ThinkingVLA 让 VLA 模型生成内部推理 token，然后再输出动作，而非直接从观测映射到动作。

### 方法架构

1. **推理头 (Reasoning Head)**: 在 VLM backbone 之后增加一个推理 token 生成模块，支持多步内部推理
2. **动作专家 (Action Expert)**: 基于推理结果生成动作的扩散 Transformer
3. **两阶段推理**: Stage 1 生成推理 token（分析任务、规划步骤），Stage 2 基于推理结果生成具体动作

### 关键创新点

- **显式推理链**: VLA 模型首次引入类似 CoT 的推理能力，将复杂的操作任务分解为中间推理步骤
- **推理-动作解耦**: 推理过程和动作生成使用不同的计算路径，推理 token 不直接影响动作维度
- **长程任务规划**: 通过内部推理，模型能够处理需要多步规划的长程操作任务

### 实验结果

在需要推理的操控任务上，ThinkingVLA 显著优于直接映射型 VLA 模型。特别是在需要工具使用、空间推理和长程依赖的任务上，推理链的效果尤为突出。

### 对具身智能工程师的启示

将推理能力引入 VLA 是一个重要趋势。对于需要多步规划或工具使用的复杂任务，纯端到端 VLA 的表现受限。ThinkingVLA 的思路是在 backbone 内部增加推理开销来换取更好的任务理解能力。实际部署时需要权衡推理延迟和任务复杂度的关系。这篇论文目前没有 HTML 版本，建议关注后续版本。

## 3. Qwen-RobotManip: 通才机器人操控模型

- **arXiv ID**: 2606.17846
- **链接**: https://arxiv.org/abs/2606.17846
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

Qwen-RobotManip 是阿里 Qwen 团队在机器人操控领域的最新工作，构建了一个大规模预训练的通才 VLA 模型。基于 Qwen2.5-VL 视觉语言模型作为 backbone，在大量跨实体机器人数据上进行预训练，实现了单模型多任务、多实体的通用操控能力。

### 方法架构

1. **Backbone**: Qwen2.5-VL 作为视觉语言理解骨干，提供强大的多模态理解能力
2. **Action Expert**: 基于 DiT (Diffusion Transformer) 的动作生成头
3. **数据规模**: 在大规模跨实体操控数据集上预训练，涵盖桌面操控、厨房场景、工具使用等
4. **训练策略**: 多阶段预训练，先在大规模混合数据上训练，再在特定任务上微调

### 关键创新点

- **大规模跨实体预训练**: 单一模型支持多种机器人实体和多种操控任务
- **Qwen-VL 强大 backbone**: 继承 Qwen 系列模型的语言理解和视觉推理能力
- **统一的动作空间**: 通过归一化设计，使不同实体的动作空间可以共享训练

### 实验结果

在 LIBERO、RLBench 等标准基准上，Qwen-RobotManip 展现了强大的跨任务泛化能力。在零样本和少样本设置下表现突出，验证了大规模预训练的有效性。

### 对具身智能工程师的启示

大模型厂商进入机器人领域是明确趋势。Qwen-RobotManip 的核心竞争力在于 Qwen-VL 的多模态理解能力和阿里积累的大规模数据。对于从业者来说，这意味着基础 VLA 模型的门槛在降低，差异化竞争点将转向数据质量、任务特定优化和部署效率。

## 4. PearlVLA: 基于 PEARL 框架的视觉语言动作模型

- **arXiv ID**: 2606.17924
- **链接**: https://arxiv.org/abs/2606.17924
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

PearlVLA 提出了一种基于 PEARL (Perception-Execution Alignment with Reinforcement Learning) 框架的 VLA 模型。核心理念是通过感知-执行对齐来弥合视觉语言理解和动作执行之间的鸿沟，使用 RL 进一步优化模型在真实环境中的表现。

### 方法架构

1. **感知-执行对齐**: 在 VLM 特征空间和动作特征空间之间建立对齐桥梁，确保视觉理解能正确转化为执行策略
2. **RL 微调**: 在预训练后使用在线 RL 进一步优化执行性能
3. **多任务联合训练**: 同时在多个操控任务上训练，利用任务间的共享知识提升泛化能力

### 关键创新点

- **感知-执行对齐机制**: 显式地对齐理解层和执行层的特征空间，减少信息丢失
- **两阶段训练范式**: 预训练阶段建立基础能力，RL 阶段优化执行质量
- **高效的特征桥接**: 通过轻量级适配器连接 VLM 和动作头

### 实验结果

在多个操控基准上，PearlVLA 的感知-执行对齐带来了显著的性能提升，特别是在需要精细空间推理的任务上。RL 微调进一步提升了成功率。

### 对具身智能工程师的启示

感知-执行对齐是 VLA 设计中的关键问题。很多 VLA 模型虽然 VLM backbone 强大，但动作生成的质量受限于 VLM 特征到动作空间的映射质量。PearlVLA 的显式对齐思路值得借鉴。

## 5. ACE-Ego-0: 自中心视角的世界模型基础模型

- **arXiv ID**: 2606.17200
- **链接**: https://arxiv.org/abs/2606.17200
- **日期**: 2026-06-16
- **类别**: cs.CV

### 核心思路

ACE-Ego-0 是一个面向自中心 (egocentric) 视角的世界模型基础模型。模型在海量第一人称视频数据上预训练，学习预测未来的视觉观测，为具身智能体提供环境建模能力。核心创新在于将世界模型与自中心表示学习结合。

### 方法架构

1. **视频预测架构**: 基于 Transformer 的视频预测模型，在自中心视频上进行自监督预训练
2. **多尺度时间建模**: 同时捕捉短期运动模式和长期场景变化
3. **动作条件生成**: 以动作为条件预测未来帧，为策略学习提供世界模型支撑

### 关键创新点

- **自中心世界模型**: 专门针对第一人称视角设计，而非通用的视频预测
- **动作条件预测**: 预测不仅仅是视觉上的，还与智能体行为耦合

### 对具身智能工程师的启示

自中心世界模型对于 VLA 和具身策略学习都是重要的基础设施组件。ACE-Ego-0 代表了"先预训练世界模型，再服务于下游任务"的范式。如果你的工作涉及世界模型辅助策略学习，这类预训练模型可以作为基础组件。

## 6. MuseVLA: 自适应多模态感知的视觉语言动作模型

- **arXiv ID**: 2606.17598
- **链接**: https://arxiv.org/abs/2606.17598
- **作者**: Xingyuming Liu, Ruichun Ma, Heyu Guo, Qixiu Li, Qingwen Yang, Lin Luo, Shiqi Jiang, Chenren Xu, Jiaolong Yang, Baining Guo
- **机构**: 北京大学 / 微软亚洲研究院 / 普林斯顿大学 / 清华大学
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

MuseVLA 将非视觉传感器（热成像、声学、毫米波雷达等）作为"按需工具"集成到 VLA 模型中，突破了现有 VLA 仅依赖 RGB 输入的局限。模型能够根据任务指令和视觉上下文，自适应选择最合适的传感器模态，并在多模态融合后生成动作。

### 方法架构

1. **Sensor Tokens**: 引入可学习的传感器 token (<None>, <Thermal>, <Acoustic>, <mmWave>)，模型根据任务生成对应的 token 来"调用"传感器
2. **Grounded Sensor Image**: 将异构传感器数据（热力图、雷达响应等）空间对齐到目标物体区域，叠加在 RGB 图像上，形成统一的中间表示
3. **Grounded Sensor Image 构造**: 使用 SAM3 进行语义分割获取目标区域 mask，然后将传感器热力图叠加到 mask 区域
4. **数据合成管线**: 从现有 RGB 机器人数据集自动生成多模态训练数据，注入物理关键词指令并叠加颜色编码 mask
5. **模型 Backbone**: PaliGemma-2 作为 VLM backbone，DiT 作为动作专家，使用 VITRA 预训练权重初始化

### 关键创新点

- **传感器即工具 (Sensor-as-Tool)**: 将传感器调用类比为 LLM 中的工具调用 (tool use)，传感器 token + 目标描述 = 带参数的工具调用
- **Grounded Sensor Image 统一表示**: 不需要为每种传感器设计专用编码器，通过空间对齐统一到 RGB 空间
- **自适应传感器选择**: 模型根据任务需求动态选择传感器，而非静态融合所有模态
- **零成本数据合成**: 从纯 RGB 数据自动合成多模态训练数据，无需昂贵的多传感器数据采集

### 实验结果

- 在真实灵巧手操控平台上测试了三类任务：温度引导的抓取放置、音频驱动物体搜索、雷达辅助隐藏物体检索
- **平均成功率 80.6%**，比 RGB-only baseline 高 58%，比原始传感器热力图 VLA baseline 高 47%
- 在未见任务上训练自合成数据集的模型实现了 66.7% 的零样本成功率
- 传感器选择准确率高，模型能有效识别何时需要非视觉感知

### 对具身智能工程师的启示

MuseVLA 的"传感器即工具"范式非常有启发性。在实际机器人系统中，RGB 相机的信息往往不足以完成所有任务（比如判断温度、检测遮挡物体）。将传感器调用机制集成到 VLA 中，并使用 grounded sensor image 作为统一表示，是一个实用的工程方案。数据合成管线也降低了多模态训练的数据门槛。这篇论文来自 MSRA，工程质量较高。

## 7. EgoInfinity: 万维 4D 手-物交互数据引擎

- **arXiv ID**: 2606.17385
- **链接**: https://arxiv.org/abs/2606.17385
- **作者**: Gaotian Wang, Kejia Ren, Andrew Morgan, Yiting Chen, Howard H. Qian, Podshara Chanrungmaneekul, Kaiyu Hang
- **机构**: Rice University / Robotics and AI Institute
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

EgoInfinity 是一个全自动的 4D 操控数据引擎，将互联网视频（如 Action100M 的 14.6 年操作视频）自动转换为可用于机器人训练的 metric 4D 手-物交互数据，包括手部轨迹、6-DoF 物体位姿和接触状态。同时提供跨实体运动重定向方法，将恢复的人类手部运动转换为不同形态机器人的可执行关节轨迹。

### 方法架构

1. **模块化管线架构**: 手部姿态估计 (WiLoR/MANO) → 物体发现与分割 (SAM3/SAM2/SAM-3D) → 深度估计 (Flow3r) → 相机标定 (MoGe-2, GeoCalib) → 物体跟踪 (FoundationPose++) → 交互感知精炼
2. **统一度量几何**: 所有模块的输出对齐到共享的度量相机坐标系，确保手部和物体在同一 3D 空间中
3. **交互感知精炼**: 利用检测到的交互状态来校正物体轨迹，减少纯视觉跟踪的漂移
4. **跨实体重定向**: 估计机器人特定的根变换，在目标机器人约束内保持任务相关的手部运动
5. **输出**: Metric 4D hand-object 交互表示，包括手部网格、关键点、物体点云、物体网格、6-DoF 位姿轨迹

### 关键创新点

- **全自动管线**: 从互联网视频到机器人可执行数据的完全自动化，无需人工标注
- **跨模块度量校准**: 统一坐标系和度量尺度，而非简单拼接独立模块
- **交互感知精炼**: 利用交互状态（接触、抓取）来校正视觉跟踪的误差
- **跨实体泛化**: 重定向方法适用于任意视角和部分可见的人体（无需完整身体姿态）
- **Action100M 数据集**: 基于引擎处理的大规模 4D 操控数据集

### 实验结果

- 在感知保真度、运动学可行性、接触一致性和跨实体泛化性上全面验证
- 真实机器人上验证了抓取、切割、擦拭、倾倒等技能的学习
- 交互感知精炼显著减少了物体跟踪漂移
- 重定向方法在多种机器人形态上成功迁移人类操作技能

### 对具身智能工程师的启示

EgoInfinity 代表了"从互联网视频到机器人行为"的可扩展路径。数据是具身智能的核心瓶颈，而互联网视频是最丰富的操作知识来源。EgoInfinity 的模块化设计使其能持续受益于感知模块的进步。对于需要大规模操控数据的团队，这类数据引擎是非常有价值的工具。开源页面在 HuggingFace 上。

## 8. HumanoidArena: 人形机器人分层全身学习的评测基准

- **arXiv ID**: 2606.17833
- **链接**: https://arxiv.org/abs/2606.17833
- **作者**: Taowen Wang, Zikang Xie, Bin Yang 等
- **机构**: 香港科技大学 (广州) / 北京工业大学 / 哈工大 (深圳) / 深圳北理莫斯科大学 / 京东探索研究院
- **日期**: 2026-06-16
- **类别**: cs.RO

### 核心思路

HumanoidArena 是一个面向人形机器人自中心分层全身学习的仿真评测基准。核心思想是将策略学习形式化为分层决策问题：高层策略将自中心视觉、本体感觉和指令转换为紧凑的全身动作，低层通用运动追踪器 (GMT) 将其执行为稳定的人形运动。基准设计了 7 个下肢关键 (leg-critical) 的交互任务，强调下肢协调在任务完成中的结构必要性。

### 方法架构

1. **分层全身协议**: 高层策略 → 中间全身动作表示 → 低层 GMT 执行
2. **7 个下肢关键任务**: 包括踢球 (Football)、双桌搬运 (DoubleDesk)、抓取搬运箱子 (P&PBox)、开门 (OpenDoor)、坐沙发 (SitSofa)、拳击 (Boxing)、视觉导航 (VisNavi)
3. **评测维度**: 扰动条件泛化 + GMT 条件迁移，从感知、语义、空间执行和追踪器部署四个维度评测
4. **数据收集管线**: 在 Isaac Gym 中收集演示数据，提供标准化的状态-动作格式

### 关键创新点

- **Policy-Tracker 接口作为评测轴**: 将策略-追踪器接口本身作为基准评测维度，而非仅评测端到端性能
- **下肢关键任务设计**: 7 个任务的成功都结构性依赖下肢协调（足部放置、平衡维持、姿态调整），而非简单搬运
- **Cross-GMT 迁移评测**: 评测高层策略在不同低层追踪器之间的迁移能力，诊断中间动作表示的通用性
- **多维度评测**: 同时评测感知鲁棒性、语义基础、空间执行和追踪器部署偏移

### 实验结果

- 分层控制使学习的策略能解决多样化的下肢关键交互任务
- 性能强烈依赖追踪器选择 (tracker-conditioned)
- 跨 GMT 迁移仍然脆弱，表明中间动作表示的通用性有待提升
- 不同策略在扰动泛化和 GMT 迁移上表现出不同模式

### 对具身智能工程师的启示
